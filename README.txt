СТРОЕВОЙ КОНСПЕКТ — пакет для публикации на GitHub Pages

ЧТО ВНУТРИ
- index.html — интерфейс приложения
- manifest.webmanifest — настройки установки как PWA
- sw.js — кеширование приложения для офлайн-запуска после первой загрузки
- icon.svg — иконка

ВАЖНО
1. Это личный клиентский прототип. Документы и настройки сохраняются в браузере на конкретном устройстве.
2. Синхронизация между устройствами и серверное хранение пока НЕ реализованы.
3. Не загружайте в GitHub личные конспекты или резервные копии: в репозитории находятся только файлы приложения.
4. Нормативные привязки основаны на загруженном экземпляре Строевого устава 2006 года; актуальность редакции отдельно не подтверждена.

ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES
1. Войдите на https://github.com/ или создайте аккаунт.
2. Создайте новый репозиторий (кнопка New).
3. Назовите его, например, stroevoy-konspekt.
4. Для наиболее простого бесплатного запуска выберите Public. Не добавляйте в репозиторий личные документы.
5. Нажмите Add file → Upload files.
6. Распакуйте этот ZIP на компьютере и загрузите СОДЕРЖИМОЕ папки в корень репозитория: index.html, manifest.webmanifest, sw.js, icon.svg.
7. Нажмите Commit changes.
8. Откройте Settings → Pages.
9. В разделе Build and deployment выберите Deploy from a branch.
10. В Branch выберите main и папку /(root), затем Save.
11. Подождите публикации. Адрес будет вида:
    https://ВАШ-ЛОГИН.github.io/stroevoy-konspekt/

УСТАНОВКА НА IPHONE
1. Откройте полученную HTTPS-ссылку именно в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» (при необходимости — «Изменить действия»).
4. Подтвердите добавление и запускайте приложение с нового значка.

ПРОВЕРКА
- Проверьте переходы между вкладками.
- Создайте тестовый черновик и сохраните его.
- Перейдите в «Мои конспекты», откройте и удалите тестовый документ.
- В «Настройках» сохраните тестовые значения.
- После первой загрузки проверьте запуск при временно отключённом интернете.

Если интерфейс не реагирует, откройте сайт в Safari, обновите страницу и пришлите скриншот или адрес опубликованного сайта. Не публикуйте пароли и токены доступа.
