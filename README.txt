Конспект командира — прототип 0.5

Загрузка в GitHub Pages:
1. Распакуйте архив.
2. В репозитории stroevoy-konspekt загрузите index.html, manifest.webmanifest, sw.js и icon.svg в корень, заменив прежние файлы.
3. Убедитесь, что Settings → Pages публикует ветку main из корневой папки.
4. Откройте опубликованный адрес в Safari на iPhone → Поделиться → На экран Домой.

Функции: каталог статей 27–38; поля занятия; генерация документа; редактирование перед печатью; сохранение в localStorage; экспорт/импорт JSON; PWA-кэш.

Важно: это прототип, не утверждённый служебный документ. Тексты нормативных положений перенесены из пользовательского PDF, страницы 7–10. Сценарии для уровня подразделения и распределение времени — предварительные методические заготовки, не требования Устава. Перед использованием проверьте редакцию Устава, программу подготовки и содержание плана у ответственного командира.
