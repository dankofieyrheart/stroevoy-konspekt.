Конспект командира — версия 0.7

Формат соответствует примеру пользователя: план-конспект воинской части с блоком утверждения и таблицей действий руководителя и обучаемых.
Для темы «Строевая стойка» (статья 27 предоставленного PDF) добавлен отдельный подробный сценарий для отделения, взвода, роты и батальона. Он также учитывает выбранную роль руководителя в титульных реквизитах. Сценарий является методической заготовкой, а не текстом Устава.
Для остальных тем пока остаётся базовая структура генератора; их подробные сценарии будут добавляться по очереди после сверки соответствующих статей.
