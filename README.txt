КОНСПЕКТ КОМАНДИРА — версия 0.8

Состав:
- index.html — приложение
- manifest.webmanifest — параметры PWA
- sw.js — офлайн-кэширование
- icon.svg — значок
- README.txt — инструкция

В версии 0.8:
- добавлен подробный сценарий по статье 28 для отделения, взвода, роты и батальона;
- для статей 27 и 28 различается формулировка действий командира подразделения и назначенного руководителя занятия;
- исправлена нумерация строк таблицы;
- время пяти этапов основной части распределяется без потери/добавления минут;
- остальные статьи 29–38 пока используют общий сценарий и требуют последовательной детализации.

Нормативные положения основаны на предоставленном пользователем экземпляре «Строевой устав.pdf».
Методика, формулировки целей и распределение времени являются проектом конспекта, а не дословными требованиями Устава.

Запуск: открыть index.html в браузере или разместить файлы в корне GitHub Pages.
Для обновления установленной PWA может потребоваться закрыть приложение и обновить страницу после смены версии кэша.
