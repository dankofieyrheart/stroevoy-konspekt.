СТРОЕВОЙ КОНСПЕКТ — версия 0.3

Обновление:
- Редактор общих сведений, учебной цели и вопросов.
- Редактируемые этапы занятия и действия руководителя/обучаемых.
- Предпросмотр документа, экспорт HTML, печать / сохранение в PDF.
- Сохранение и повторное редактирование конспектов.
- Резервное копирование и восстановление конспектов через JSON.
- Уточнение, что нормативные привязки основаны на загруженном экземпляре Устава 2006 года и не подтверждают его актуальность.

УСТАНОВКА В СУЩЕСТВУЮЩИЙ GITHUB REPOSITORY
1. Распакуйте архив.
2. Откройте репозиторий на GitHub → Add file → Upload files.
3. Загрузите файлы из архива в корень репозитория и подтвердите Commit changes.
4. Если GitHub спросит про одинаковые имена, загрузите с заменой (новый index.html, manifest.webmanifest, sw.js, icon.svg).
5. Откройте сайт в Safari и обновите страницу. При старом кэше закройте вкладку, откройте снова; при необходимости удалите веб-приложение с экрана Домой и добавьте заново.

ОГРАНИЧЕНИЯ
- Конспекты хранятся в localStorage конкретного браузера/устройства.
- Автоматической синхронизации между устройствами пока нет.
- DOCX-экспорт не включён; доступны HTML и печать/PDF.
- Для темы без подтверждённой привязки укажите источник вручную.
- Проверьте статью в оригинале и действующей редакции перед использованием.
